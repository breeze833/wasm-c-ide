Turtle Graphics (<turtle.h>)

Complete API reference for educational C turtle graphics, featuring Cartesian geometry, animation frame pacing, and link-time verified backends.

1. The Cartesian Coordinate Plane

libturtle uses a mathematical Cartesian coordinate system:

                    +Y (North / 90°)
                           ▲
                           │
          -X (West / 180°) ┼ ───► +X (East / 0°)
                         (0,0)
                           │
                           ▼
                    -Y (South / 270°)
  • Origin (0, 0): The exact geometric center of the canvas.
  • X Axis: +X extends to the Right (East), -X extends to the Left (West).
  • Y Axis: +Y extends Upward (North), -Y extends Downward (South).
  • Angular Headings: Standard math convention (counter-clockwise is positive):
    • 0.0°: East (+X)
    • 90.0°: North (+Y)
    • 180.0°: West (-X)
    • 270.0°: South (-Y)

2. Backend Initialization & Link-Time Safety

Programs initialize using the convenience macro turtle_begin(ctx). The macro expands to call the backend-specific initializer followed by turtle_begin_core(), guaranteeing that the program will fail to link if linked against an incorrect backend archive.

Canvas-WASI Backend (Default HTML5 Canvas)

#include "turtle.h"
#include "turtle_backend_canvas_wasi.h"

int main(void) {
    turtle_canvas_wasi_context_t ctx = {
        .width = 800,
        .height = 600,
        .title = "WASI Turtle Window"
    };
    if (!turtle_begin(&ctx)) return 1;

    turtle_clear(TURTLE_BLACK);
    turtle_pen_color(TURTLE_RED);
    turtle_forward(100.0);
    turtle_turn_left(90.0);
    turtle_forward(100.0);

    turtle_delay(2000.0);
    turtle_end();
    return 0;
}

Raylib Desktop/WASI Backend

#include "turtle.h"
#include "turtle_backend_raylib.h"

int main(void) {
    turtle_raylib_context_t ctx = {
        .width = 800,
        .height = 600,
        .title = "Raylib Turtle",
        .target_fps = 60
    };
    if (!turtle_begin(&ctx)) return 1;

    turtle_clear(TURTLE_WHITE);
    turtle_pen_color(TURTLE_BLUE);
    for (int i = 0; i < 36; i++) {
        turtle_forward(100.0);
        turtle_turn_right(170.0);
        turtle_delay(25.0);
    }

    turtle_end();
    return 0;
}

3. Complete Core API Reference

3.1 Lifecycle & Canvas Control

Function SignatureDescription
bool turtle_begin_core(void); Low-level initialization of turtle state machine. Called automatically by turtle_begin(ctx).
void turtle_end(void); Cleans up resources, frees allocated textures/buffers, and closes the canvas window.
void turtle_clear(uint32_t color); Clears the entire canvas surface with the specified 32-bit RGBA color.
void turtle_home(void); Returns turtle to origin (0, 0) and resets heading to 0.0° (East). Existing drawing is preserved.
void turtle_delay(double ms); Pauses execution for ms milliseconds, flushes lines to the display canvas, and paces interactive drawing without CPU busy-looping.

3.2 Movement & Orientation

Function SignatureDescription
void turtle_forward(double steps); Moves the turtle along its current heading by steps pixels. Positive moves forward; negative moves backward. Draws a line if pen is down.
void turtle_turn(double deg); Rotates the turtle heading by deg degrees following mathematical convention (Counter-Clockwise is positive).
void turtle_turn_left(double deg); Rotates the turtle counter-clockwise (to the left) by deg degrees.
void turtle_turn_right(double deg); Rotates the turtle clockwise (to the right) by deg degrees.

3.3 Pen State Management

Function SignatureDescription
void turtle_pen_down(void); Lowers the pen. Subsequent turtle movement draws lines.
void turtle_pen_up(void); Raises the pen. Subsequent turtle movement does not draw lines.
int turtle_is_pen_down(void); Returns 1 if the pen is down, or 0 if raised.
void turtle_pen_stroke(double stroke); Sets the pen line width in pixels.
void turtle_pen_color(uint32_t color); Sets the pen color via packed 32-bit RGBA value (0xRRGGBBAA).
void turtle_pen(double stroke, uint32_t color, int is_down); Convenience function setting stroke width, color, and pen up/down state in a single call.

3.4 Cursor Visibility

Function SignatureDescription
void turtle_set_visible(bool visible); Controls whether the stylized turtle cursor icon is displayed on the canvas.
bool turtle_is_visible(void); Returns true if the turtle cursor is currently visible.

3.5 State Inspection

Function SignatureDescription
double turtle_get_x(void); Returns the current turtle X coordinate relative to center origin (0, 0).
double turtle_get_y(void); Returns the current turtle Y coordinate relative to center origin (0, 0).
double turtle_get_heading(void); Returns current heading in degrees [0.0, 360.0). 0° = East, 90° = North.
