Zero-Install, Client-Side Architecture

wasm-c-ide executes Clang/LLVM 19, GNU Make, BusyBox shell, and user-compiled binaries entirely inside modern web browsers using WebAssembly. No server compilation, no container overhead, and full offline PWA support.

General C Libc & WASI Limits

Understand the WebAssembly sandbox constraints: no fork/exec, single-threaded execution, synchronous clocks via poll_oneoff, and in-memory VFS.

Quick Start Example

Here is a minimal C program demonstrating direct standard I/O and mathematics:

#include <stdio.h>
#include <math.h>

int main(void) {
    printf("Hello from WebAssembly C IDE!\n");
    for (int i = 0; i <= 5; i++) {
        printf("sqrt(%d) = %.4f\n", i, sqrt((double)i));
    }
    return 0;
}
