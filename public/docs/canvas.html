Canvas 2D & Direct Software Framebuffer

Complete C/C++ API reference for low-level software framebuffers (<graphics.h>) and HTML5 2D vector primitives (<graphics_canvas.h>) via canvas-wasi.

Zero Linker Flags Guarantee

All functions declared in <graphics.h> and <graphics_canvas.h> are resolved directly by WebAssembly host imports provided by the browser environment (under the env namespace). When compiling in wasm-c-ide or using clang --target=wasm32-wasi, no external -l linker flags are required.

Part 1: Software Framebuffer API (<graphics.h>)

1.1 Window Lifecycle & Control

Function SignatureDescription
void graphics_init(int width, int height, const char *title); Initializes the graphics display window with logical dimensions (e.g. 640x480) and title bar string. Opens the floating canvas window in the UI.
bool graphics_should_close(void); Returns true if the user has requested closing the window (via the close button or shortcut).
void graphics_close(void); Requests closing and hiding the graphics window from within C code.

1.2 Frame Presentation & Memory Layout

Function SignatureDescription
void graphics_present(const uint32_t *pixels); Copies a full-screen buffer of width * height 32-bit pixels directly to the display canvas.
void graphics_present_rgba(const uint8_t *rgba, int width, int height); Transfers a raw byte array of RGBA pixels with explicit dimensions to the screen.
Pixel Format (Little-Endian 0xAABBGGRR)

In memory (from byte 0 to byte 3):

  • Byte 0: Red (0 - 255)
  • Byte 1: Green (0 - 255)
  • Byte 2: Blue (0 - 255)
  • Byte 3: Alpha (0 - 255)

Helper macro: #define RGBA(r,g,b,a) (((uint32_t)(a)<<24)|((uint32_t)(b)<<16)|((uint32_t)(g)<<8)|(uint32_t)(r))

Minimal Framebuffer Starter Template

#include <graphics.h>
#include <stdint.h>

#define WIDTH 640
#define HEIGHT 480
#define RGBA(r,g,b,a) (((uint32_t)(a)<<24)|((uint32_t)(b)<<16)|((uint32_t)(g)<<8)|((uint32_t)(r)))

int main(void) {
    graphics_init(WIDTH, HEIGHT, "Direct Software Framebuffer");
    static uint32_t fb[WIDTH * HEIGHT];

    while (!graphics_should_close()) {
        for (int i = 0; i < WIDTH * HEIGHT; i++) {
            fb[i] = RGBA(255, 128, 0, 255); // 32-bit RGBA orange
        }
        graphics_present(fb);
        graphics_wait_frame(60);
    }

    graphics_close();
    return 0;
}

1.3 Frame Pacing

Function SignatureDescription
void graphics_wait_frame(int target_fps); Synchronously sleeps the remainder of the frame duration using host Atomics.wait(), pacing rendering cleanly at 60 FPS without CPU busy-looping.

1.4 Synchronous Input Handling

Function SignatureDescription
void graphics_get_mouse(int *x, int *y, int *buttons, int *wheel); Reads current mouse position (*x, *y) in render pixels, mouse button bitmask (*buttons: 1 = Left, 2 = Middle, 4 = Right), and vertical wheel delta (*wheel).
bool graphics_is_key_down(int key); Queries whether the specified virtual keycode is currently held down (e.g. 27 for Escape, 32 for Space, 37-40 for Arrow keys, 256 for Enter).

Part 2: HTML5 Canvas 2D Vector API (<graphics_canvas.h>)

2.1 Frame Presentation

Function SignatureDescription
void canvas_present(void); Flushes all vector rasterization commands off-thread and presents the updated surface to the canvas display window. Content is preserved across frames.

Minimal Vector Canvas Starter Template

#include <graphics_canvas.h>

int main(void) {
    graphics_init(800, 600, "Canvas 2D Vector API");

    while (!graphics_should_close()) {
        canvas_clear_rect(0, 0, 800, 600);

        canvas_set_fill_style("#00e5ff");
        canvas_fill_rect(100, 100, 200, 150);

        canvas_begin_path();
        canvas_arc(500, 200, 60, 0, 6.283185f, false);
        canvas_set_fill_style("#ff5722");
        canvas_fill();

        canvas_present();
        graphics_wait_frame(60);
    }

    graphics_close();
    return 0;
}
