Raylib 5.5 WebAssembly Port

Official Raylib 5.5 compiled to pure WASI Preview 1 via WebGL ES 2.0, Web Audio, and SharedArrayBuffer frame pacing.

WASI Preview 1 Restrictions Matrix

Upstream Raylib source is 100% clean and unmodified, but WebAssembly runs under the following constraints:

Feature / SubsystemStatusTechnical Details
Core & Windowing Supported InitWindow, WindowShouldClose, CloseWindow, SetWindowTitle.
2D & 3D Graphics Supported Shapes, Textures, RenderTextures, Fonts, Models, and WebGL ES 2.0 (rlgl).
Frame Pacing Supported SetTargetFPS(60) clamped cleanly using host WaitTime() and Atomics.wait().
Web Audio Supported Hardware-decoupled Web Audio subsystem (raudio_wasi.c) streaming to browser AudioContext.
Immediate GUI (raygui) Supported Include <raygui.h> with #define RAYGUI_IMPLEMENTATION for 25+ UI controls.
Multi-Threading Disabled No pthreads. Background async loading must be processed incrementally on main thread.
Native Desktop Handles Disabled GLFW window pointers, OS file drop callbacks, and hardware cursor locks are not available.

Interactive Starter Template

#include "raylib.h"

int main(void) {
    const int screenWidth = 800;
    const int screenHeight = 450;

    InitWindow(screenWidth, screenHeight, "Raylib 5.5 - wasm-c-ide");
    SetTargetFPS(60);

    Vector2 ballPosition = { (float)screenWidth / 2, (float)screenHeight / 2 };

    while (!WindowShouldClose()) {
        if (IsKeyDown(KEY_RIGHT)) ballPosition.x += 4.0f;
        if (IsKeyDown(KEY_LEFT))  ballPosition.x -= 4.0f;
        if (IsKeyDown(KEY_UP))    ballPosition.y -= 4.0f;
        if (IsKeyDown(KEY_DOWN))  ballPosition.y += 4.0f;

        BeginDrawing();
        ClearBackground(RAYWHITE);
        DrawCircleV(ballPosition, 30, MAROON);
        DrawText("Move the ball with arrow keys", 10, 10, 20, DARKGRAY);
        EndDrawing();
    }

    CloseWindow();
    return 0;
}
